# ERP 面试复习手册

适合手机阅读的中文面试资料页面。包含岗位准备、汉得经历线、ERP 场景追问、岗位问答、模拟面试和经历核实。叙事为：学校用友 U8 打底，冲着 ERP 业务投汉得，入职后分到企业 Agent 平台做 Spring Boot + Vue 接口联调，ERP 只参与少量接口对接。具体页面与项目名仍待核实；采购申请等模块仅作设计练习。

支持全文搜索、可分享的章节链接、折叠问答、字号调整、夜间阅读和打印。模拟面试从 40 道题随机抽取，同一轮不重复，参考答案默认隐藏；支持标记未掌握和只练未掌握。标记保存在当前浏览器，刷新后保留，不跨设备同步；存储受限时页面会显示提示。

发布页是一个自包含的 `index.html`，没有外部运行时、字体或统计脚本。下载该文件后也可以直接离线打开；首次打开在线地址仍需网络。

## 更新

修改 `sources/` 中的 Markdown、`reader.css`、`reader.js` 或 `interview.html`，安装开发依赖后运行 `npm run build`。生成检查会验证问题数量、链接和发布内容，构建结果随主分支提交，由 GitHub Pages 从仓库根目录发布。

模拟面试的浏览器检查保存在 `checks/interview.js`。本地静态服务启动后，用 Playwright CLI 打开 `/#interview`，再运行 `playwright-cli run-code --filename=checks/interview.js`。检查会验证隐藏答案、整轮不重复、标记持久化、未掌握筛选和手机布局；请在独立测试浏览器中运行，它会清空该测试来源的未掌握标记。

网页公开可访问。仓库只包含本次学习资料与网页源码，不包含原始简历、联系方式、凭据或个人电脑路径。
