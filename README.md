# ERP 面试复习手册

适合手机阅读的中文面试资料页面。包含岗位准备、ERP 项目口述、事务与分页追问、岗位问答、模拟面试和经历核实。采购申请等具体模块与故障为待核实练习场景。

支持全文搜索、可分享的章节链接、折叠问答、字号调整、夜间阅读和打印。发布页是一个自包含的 `index.html`，没有外部运行时、字体或统计脚本。下载该文件后也可以直接离线打开；首次打开在线地址仍需网络。

## 更新

修改 `sources/` 中的 Markdown、`reader.css` 或 `reader.js`，安装开发依赖后运行 `npm run build`。生成检查会验证问题数量、链接和发布内容，构建结果随主分支提交，由 GitHub Pages 从仓库根目录发布。

网页公开可访问。仓库只包含本次学习资料与网页源码，不包含原始简历、联系方式、凭据或个人电脑路径。
